# T04 — 数据读写流实现（open / create / append）

## 目标

实现 `CephInputStream`、`CephOutputStream`，补全 `CephFileSystem` 的
`open` / `create` / `append`，达成真实集群上大文件读写字节级一致。

## 前置依赖

T03 DONE。必读：架构文档 §3.2（create/append 行）、§3.3、§4-5（块大小映射）；
Hadoop 规范 `filesystem/fsdatainputstream.md`、`outputstream.md`
（位于 hadoop-3.3.6-src 同目录）。

## 工作内容

1. **`CephInputStream extends FSInputStream`**：
   - 构造时接收 proto、fd、文件长度、缓冲大小（`ceph.client.buffer.size`）；
   - `read()`/`read(byte[],off,len)` 经内部缓冲；`seek` 缓冲内命中则移动指针，
     否则失效缓冲并记录新 pos（实际 lseek 可延迟到下次读）；
   - `getPos`、`seekToNewSource`（return false）、`available`；
   - `close()` 幂等释放 fd；关闭后一切读操作抛 `IOException`（规范要求）。
2. **`CephOutputStream extends OutputStream implements Syncable, StreamCapabilities`**：
   - 内部写缓冲，满则 `proto.write`；`flush()` 刷 Java 缓冲；
   - `hflush()`/`hsync()` → 刷缓冲 + `proto.flush(fd)`（ceph fsync）；
   - `hasCapability`：`hflush`/`hsync` 返回 true；
   - `close()` 幂等：刷缓冲 → fsync → 释放 fd。
3. **`CephFileSystem` 三方法**：
   - `open(path, bufferSize)`：目录→`FileNotFoundException` 语义检查；
     `O_RDONLY` 打开，`ceph.localize.reads` 生效（`CephMount` 的 localize 调用，
     以 16.2.14 实际 API 为准）；
   - `create(path, perm, overwrite, bufferSize, replication, blockSize, progress)`：
     已存在且 !overwrite→`FileAlreadyExistsException`；已存在目录→同异常；
     父目录不存在→按 Hadoop 语义自动 mkdirs（父路径为文件→`ParentNotDirectoryException`）；
     blockSize 参数 → open 的 layout（object_size=blockSize，stripe_unit 取
     min(blockSize, 默认 stripe)，stripe_count=1；`ceph.data.pools` 生效）；
     `createNonRecursive` 一并实现（父不存在→异常）；
   - `append(path, bufferSize, progress)`：不存在→`FileNotFoundException`；
     `O_WRONLY|O_APPEND` 打开（注意：append 模式下 CephOutputStream 初始 pos
     为文件末尾）。
4. **测试**：
   - mock 单测：流的缓冲边界（跨缓冲写、缓冲内/外 seek、read 返回 -1 于 EOF、
     关闭后操作抛异常、hflush 触发 proto.flush、create 分支矩阵）；
   - `ITestCephIO`（门控）：真实集群写入 200MB（> 2×64MB object size，覆盖跨对象）
     随机数据 → md5 比对回读；随机位置 pread 抽查 100 次与本地副本一致；
     append 后长度与内容正确；`hflush` 后另开 FileSystem 实例可读到已刷数据。

## 交付物

- `CephInputStream.java`、`CephOutputStream.java`
- `CephFileSystem` 中 open/create/append 的完整实现
- mock 单测 + `ITestCephIO.java`

## 验收标准

1. `mvn clean test` 绿色（无集群）；
2. `ITestCephIO` 全部通过，含 200MB md5 一致性与随机 pread 抽查；
3. create/append/open 的异常分支与 Hadoop 规范文档一致（单测逐条对应）；
4. 无资源泄漏：集成测试结束后 proto 层打开 fd 计数归零（CephTalker 加
   计数器断言，或等效手段）。
