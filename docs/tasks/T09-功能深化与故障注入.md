# T09 — 功能深化与故障注入测试

## 目标

在生产仿真集群（E2）上补齐 v1.0.0 完全缺失的两类证据：**规模化/边界功能语义**
与**故障场景下的行为、恢复能力与数据完整性**。产出物除用例外，还包括一份
《故障场景预期行为表》与更新后的运维排查表——这是连接器能否被判定"可生产使用"
的核心依据。

## 前置依赖

T08 DONE（E2 集群与 CI 可用、契约在 E2 已跑通）。必读：`docs/TEST-PLAN.md` §5 L3、
§6 故障注入清单、附录 A；`docs/TEST-CASES.md` 的 FN-*/REL-* 两节。

## 工作内容

1. **L3 功能深化用例**（`ITest*`，实现 `FN-01`–`FN-30`）：
   - 规模与边界：1GB/10GB 文件、> 2^31 偏移 pread、1 万/10 万条目目录、
     100 层深目录、特殊文件名与长度上限、5 万 fd 打开/关闭；
   - 语义与可见性：**FN-11 读方可见性**（当前为 open 时刻长度快照）、
     `hflush`/`hsync` 持久性、kill -9 后的数据存活、并发 rename/delete/create 竞态、
     32 线程混合读写 30 min、`FileSystem.CACHE` 与多 UGI 的 mount 行为；
   - 周边：子目录挂载、Trash、`getContentSummary`、多 OSD 下的 BlockLocation 真实性、
     `Statistics` 计数准确性、13 个配置键逐项生效性。
2. **故障注入框架** `scripts/fault/`：每类故障一个可复现脚本
   （`mds-fail.sh`、`osd-down.sh`、`mon-block.sh`、`client-evict.sh`、`netem.sh`、
   `pool-full.sh`、`quota.sh`、`caps-matrix.sh`…），统一支持
   `inject → observe → recover → verify` 四段式与超时兜底，**注入失败必须能自动恢复集群**。
3. **REL-F01–F15 执行**：每条记录注入命令、客户端观测（异常类型/文本/阻塞时长）、
   恢复行为、md5 一致性结论、运维处置口径。
4. **《故障场景预期行为表》** `docs/FAULT-BEHAVIOR.md`：15 类场景 × 
   （现象 / 根因 / 是否自动恢复 / 需人工介入的动作 / 是否需产品增强）。
5. **DEPLOY.md 排查表升级**：把 L4 新复现的症状原文补入（按 T07 既有体例，
   症状文本必须来自真实复现，不得杜撰）；区分"调试构建专属"与"生产同样存在"。
6. **附录 A 结论化**：至少对 A-1（重连/重试）、A-2（可见性）、A-6（ENOSPC/配额映射）
   给出"是否需要代码增强"的书面结论与建议方案（**不实现**）。
7. **夜间流水线接入**：FN 全量 + REL 子集（F01/F03/F05/F13）进 `nightly.yml`。

## 交付物

- 新增 `ITest*` 用例 30 例（FN 段）
- `scripts/fault/*.sh` 故障注入脚本套件
- `docs/FAULT-BEHAVIOR.md`（15 类场景预期行为表）
- 更新的 `docs/DEPLOY.md` 排查表
- 缺陷单（按 S1–S4 分级）与附录 A 结论
- PROGRESS.md 登记：用例结果、故障行为摘要、缺陷清单

## 验收标准

1. `FN-01`–`FN-30` 全部执行；通过项 100%，未通过项均有缺陷单与分级；
2. `REL-F01`–`REL-F15` 全部执行，每条产出四段式记录；**S1 缺陷（数据丢失/静默损坏）
   为 0**，否则本阶段判 BLOCKED 并立即上报；
3. 所有涉及数据的故障场景 md5 校验一致（允许"未 flush 数据丢失"，但不允许
   长度与内容不一致的损坏文件）；
4. `docs/FAULT-BEHAVIOR.md` 15 行齐全，每行有真实复现命令与输出片段；
5. 故障注入脚本可在 E2 上连续跑 2 轮且集群每次都能自动恢复到 `HEALTH_OK`；
6. 夜间流水线跑通 3 次，flaky 用例已建单。

## 边界与禁止事项

- **不实现产品增强**（重连/重试、可见性刷新、异常映射扩展等）：只产出结论与建议，
  实现另立任务；
- 仅当阻塞测试执行且 < 15 分钟可修的产品缺陷可当场修复并登记；
- 故障注入只在 E2 专用集群执行，禁止在任何共享/生产环境执行；
- 不做性能基准（T10）与生态集成（T11）——遇到性能观察记为数据点交 T10。
