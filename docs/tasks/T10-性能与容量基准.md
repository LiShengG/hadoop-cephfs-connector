# T10: Performance and capacity baseline

## Scope

Create a reproducible E2 performance baseline against the same-cluster kernel CephFS mount, covering
throughput, metadata operations, latency distribution, scale, and client resource use.

## Non-goals

- Measuring before the E2 fingerprint and test procedures are reproducible.
- Hiding an integrity or reliability defect behind throughput numbers.
- Publishing results without the exact environment and commands.

## Acceptance criteria

- PERF-01–PERF-15 have three-run median and variation evidence tied to an E2 fingerprint.
- Each threshold in the test definitions is evaluated; failures have tracking and an implementation
  versus environment classification.
- Matrix and comparison entry points reproduce the measurements and reject an injected regression.
- The report quantifies the identified buffering, metadata, flush, and block-location sensitivities.
